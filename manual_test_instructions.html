🔬 Gemstone Explorer - Manual Test Instructions

📋 Test Objective: Verify that the Gemstone Explorer app loads without JavaScript errors and that the Temperature control section is visible and functional.
🚀 Open Gemstone Explorer

📝 Test Steps

Step 1: Open the Application

Click the "Open Gemstone Explorer" button above or navigate to http://localhost:8765

Step 2: Open Browser Developer Tools

Press F12 (Windows/Linux) or Cmd+Option+I (Mac) to open Developer Tools

✅ Expected: No JavaScript errors in console. Some informational messages are OK.
❌ Look for: Red error messages, "Uncaught" errors, "ReferenceError", "TypeError", etc.

Step 3: Switch to Photon Experiment Tab

Click the Photon Experiment tab at the top of the page

Step 4: Locate Temperature Control Section

Scroll down in the right sidebar to find the "Temperature" section

📍 Location: The Temperature section should be between "Mechanical / Piezoelectric" and "Magnetic Field" sections.

Step 5: Test Emit Burst Button

Click the Emit Burst button in the experiment panel header

Step 6: Test Continuous Emission

Click the Continuous button to start continuous photon emission

Step 7: Verify Temperature Stats Update

While continuous emission is running, observe the Temperature stats

💡 Tip: Increase the "Beam Power Scale" slider to see faster temperature increases.
🔍 Look for: Temperature values in the bottom-left of each cell in the Per-Crystal Analysis grid.

Step 8: Test Temperature Controls

Interact with the temperature controls to verify they work

Step 9: Final Console Check

Return to the Console tab in Developer Tools

📊 Test Results Summary

🎯 Expected Outcomes

✅ All Tests Should Pass:

  • ✅ Page loads without JavaScript errors
  • ✅ Temperature control section is visible in the Photon Experiment tab
  • ✅ All temperature controls are present and functional
  • ✅ Thermal stats update when photons are emitted
  • ✅ Per-cell temperature displays appear in the analysis grid
  • ✅ No console errors during normal operation

📚 Additional Information

🔬 Thermal Physics Features

The thermal simulation includes:

  • Heat Capacity: Debye model with temperature-dependent specific heat
  • Heating: Energy deposition from absorbed photons
  • Cooling: Convection, radiation (Stefan-Boltzmann), and conduction
  • Thermo-optic Effect: Refractive index changes with temperature
  • Band Gap Shift: Varshni model for semiconductor behavior
  • Fluorescence Quenching: Thermal quenching at high temperatures
  • Pyroelectric Effect: Voltage generation in piezoelectric crystals
  • Thermal Emission: Blackbody radiation at elevated temperatures

🐛 Troubleshooting

If the page doesn't load:

  • Verify the server is running on port 8765
  • Check the terminal for server errors
  • Try refreshing the page (Cmd+R or F5)

If temperature doesn't change:

  • Ensure "Enable thermal simulation" is checked
  • Increase "Beam Power Scale" to 10¹⁷ or 10¹⁸
  • Let continuous emission run for at least 5-10 seconds
  • Check that gems are assigned in the grid (not all empty)
