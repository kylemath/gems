## 1. Chemical Formulas and Crystal Structure

| Gemstone | Chemical Formula | Mineral Group | Crystal System | Silicate Type |
|----------|-----------------|---------------|----------------|---------------|
| **Quartz** | SiO₂ | Quartz | Trigonal | Tectosilicate (3D framework) |
| **Amethyst** | SiO₂ + trace Fe | Quartz (variety) | Trigonal | Tectosilicate |
| **Chalcedony** | SiO₂ (cryptocrystalline) | Quartz (variety) | Trigonal (microcrystalline) | Tectosilicate |
| **Agate** | SiO₂ (banded chalcedony) | Quartz (variety) | Trigonal (microcrystalline) | Tectosilicate |
| **Carnelian** | SiO₂ + Fe₂O₃ inclusions | Quartz (variety) | Trigonal (microcrystalline) | Tectosilicate |
| **Jasper** | SiO₂ + up to 20% impurities | Quartz (variety) | Trigonal (microcrystalline) | Tectosilicate |
| **Onyx** | SiO₂ (banded chalcedony) | Quartz (variety) | Trigonal (microcrystalline) | Tectosilicate |
| **Emerald** | Be₃Al₂Si₆O₁₈ + trace Cr/V | Beryl | Hexagonal | Cyclosilicate (6-rings) |
| **Aquamarine** | Be₃Al₂Si₆O₁₈ + trace Fe²⁺ | Beryl | Hexagonal | Cyclosilicate (6-rings) |
| **Garnet** (Almandine) | Fe₃Al₂(SiO₄)₃ | Garnet | Cubic | Nesosilicate (isolated) |
| **Garnet** (Pyrope) | Mg₃Al₂(SiO₄)₃ | Garnet | Cubic | Nesosilicate (isolated) |

| **Peridot** | (Mg,Fe)₂SiO₄ | Olivine | Orthorhombic | Nesosilicate (isolated) |
| **Zircon** | ZrSiO₄ | Zircon | Tetragonal | Nesosilicate (isolated) |
| **Amazonite** | KAlSi₃O₈ + trace Pb | Feldspar (microcline) | Triclinic | Tectosilicate (3D framework) |
| **Lazurite** | (Na,Ca)₈(AlSiO₄)₆(S,SO₄,Cl)₁₋₂ | Sodalite | Cubic | Tectosilicate (framework) |

## 3. Chromophores, Absorption Spectra, and Color Origin

| Gemstone | Chromophore | Key Absorption Bands (nm) | Color Mechanism | Color Produced |
|----------|------------|---------------------------|-----------------|----------------|
| **Quartz** | None (pure) | None (transparent 200–3500 nm) | — | Colorless |
| **Amethyst** | Fe⁴⁺ color center (irradiation of Fe³⁺) | 545, 357 nm | Radiation-induced charge transfer at Fe site | Purple/violet |
| **Chalcedony** | Variable | Variable | Depends on variety | Variable |
| **Agate** | Fe oxides, Mn oxides (in bands) | Band-dependent | Differential impurity banding | Banded, multicolor |
| **Carnelian** | Fe₂O₃ (hematite) submicroscopic inclusions | Broad absorption below ~550 nm | Fe³⁺ ligand field + Fe₂O₃ inclusions | Red-orange |
| **Jasper** | Fe₂O₃ (hematite), up to 20% | Broad visible absorption | Fe₂O₃ particulate inclusions | Red, brown, yellow |
| **Onyx** | Carbon, Fe oxides | Broad absorption across visible | Carbon and oxide inclusions | Black, banded |
| **Emerald** | Cr³⁺ (primary), V³⁺ (secondary) | 683, 680, 662, 646, 637, 606, 594 nm | Cr³⁺ crystal field d–d transitions | Green |
| **Aquamarine** | Fe²⁺ (intervalence w/ Fe³⁺) | Broad band ~810 nm (near-IR); ~370 nm | Fe²⁺ → Fe³⁺ charge transfer | Blue to blue-green |
| **Garnet** (Almandine) | Fe²⁺ (8-fold coord.) | 505, 520, 576 nm (3 main bands) | Fe²⁺ crystal field transitions | Deep red |
| **Garnet** (Pyrope) | Cr³⁺ + Fe²⁺ | 505, 520, 576 nm (Fe²⁺); Cr³⁺ fine lines | Fe²⁺ field + Cr³⁺ contributions | Red to purplish-red |
| **Garnet** (Spessartine) | Mn²⁺ | 410, 422, 432, 460, 482 nm (Mn²⁺ series) | Mn²⁺ d–d transitions | Orange |
| **Peridot** | Fe²⁺ | 653, 529, 497, 493, 473, 453 nm | Fe²⁺ crystal field in M1 and M2 sites | Yellow-green |
| **Zircon** | U⁴⁺ (+ radiation damage centers) | 653.5 nm (diagnostic), up to 40 lines | U⁴⁺ f–f transitions; radiation damage | Variable (blue, yellow, brown, green) |
| **Amazonite** | Pb⁺ and Pb³⁺ | Pb⁺ absorption at 1.6–1.8 eV (~690–775 nm) | Pb⁺ substitutes for K⁺; Pb³⁺ adds blue | Blue-green |
| **Lazurite** | S₃⁻ (trisulfur radical anion) | ~600 nm (strong, broad) | S₃⁻ molecular orbital transitions | Intense blue |

**Sources:** [CIT], [GLT], [UTA], [GIA-PL], [SPR]; amazonite: Hofmeister & Rossman, Min. Mag. 49 (1985); lazurite: Sapozhnikov et al., Minerals 10, 1042 (2020)

## 7. Summary Comparison: Why Chemistry Determines Function

```
SiO₂ backbone (Quartz family)
│
├─ Pure SiO₂ → Colorless, piezoelectric, extreme insulator (10¹⁸ Ω·cm)
│   ├─ + Fe⁴⁺ color center → Amethyst (purple, still piezoelectric)
│   ├─ + Fe₂O₃ inclusions → Carnelian (red, no piezo — polycrystalline)
│   ├─ + Fe₂O₃ particulates → Jasper (red/brown, opaque)
│   └─ + banding → Agate / Onyx (decorative, no unique photonic use)
│
├─ Be₃Al₂Si₆O₁₈ framework (Beryl)
│   ├─ + Cr³⁺ → Emerald (green, red fluorescence at 683 nm)
│   └─ + Fe²⁺ → Aquamarine (blue, no fluorescence)
│
├─ X₃Y₂(SiO₄)₃ framework (Garnet)
│   ├─ X = Fe²⁺ → Almandine (deep red, high RI 1.83)
│   ├─ X = Mg²⁺ → Pyrope (red, moderate RI)
│   └─ X = Mn²⁺ → Spessartine (orange, weak fluorescence)
│
├─ (Mg,Fe)₂SiO₄ → Peridot (green, very high birefringence, Cr:forsterite laser host)
├─ ZrSiO₄ → Zircon (highest RI/dispersion, U⁴⁺ absorption at 653.5 nm)
├─ KAlSi₃O₈ + Pb → Amazonite (blue-green from Pb⁺/Pb³⁺)
└─ (Na,Ca)₈(AlSiO₄)₆S → Lazurite (blue from S₃⁻ radical anion)
```
